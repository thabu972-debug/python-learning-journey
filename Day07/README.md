## 💻 Program Practiced

### 🛒 Order Discount Calculator

The program checks the order amount and applies a discount based on different price ranges.

| Order Amount | Discount |
|---|---:|
| ₹500 or above | 20% |
| ₹300 – ₹499 | 10% |
| ₹100 – ₹299 | 5% |
| Below ₹100 | 0% |

The program calculates:

```text
Discount = Order Amount × Discount Percentage / 100
```

Then:

```text
Final Amount = Order Amount - Discount
```
