# 📘 Day 8 - Python For Loops

Welcome to **Day 8** of my Python learning journey! 🐍

Today I practiced **`for` loops** in Python and learned how to repeat operations over lists and ranges.

---

## 📚 Topics Covered

* `for` loop
* Iterating through lists
* `range()` function
* Counting values based on a condition
* Incrementing variables inside loops
* Reverse looping
* Calculating a running total
* `break` statement

---

## 💻 Programs Practiced

### 🥕 Task 1 - Loop Through Vegetables

Created a list of vegetables and used a `for` loop to print each vegetable individually.

### 💰 Task 2 - Count Prices Above 100

Looped through a list of prices and counted how many prices were greater than `100`.

### 🔢 Task 3 - Print Even Numbers

Used `range()` to print even numbers from `2` to `20`.

### 🔽 Task 4 - Countdown

Used a reverse `range()` to print numbers from `5` down to `1`, followed by `"done"`.

### 🛒 Task 5 - Calculate Total

Used a `for` loop to calculate the running total of values in a list.

---

## 🎯 Learning Outcomes

By completing these programs, I learned how to:

* Iterate through list elements using `for`.
* Use `range()` with start, stop, and step values.
* Count values that satisfy a condition.
* Use a variable to maintain a running total.
* Create a countdown using reverse ranges.
* Understand how `break` can be used to stop a loop.
