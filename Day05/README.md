# 📙 Day 5 - Python Tuples, Sets & Dictionaries

Welcome to **Day 5** of my Python learning journey! 🚀

Today I practiced three important Python data structures: **Tuples, Sets, and Dictionaries**. These structures help organize and manage data efficiently in different ways.

---

## 📚 Topics Covered

### 📦 Tuples
- Tuple slicing
- Counting occurrences with `count()`
- Membership operator (`in`)

### 🔢 Sets
- Creating sets
- Adding elements using `add()`
- Removing elements using `remove()`
- Finding the number of unique elements using `len()`

### 📖 Dictionaries
- Creating dictionaries
- Accessing values using keys
- Viewing dictionary keys
- Updating values using `update()`

---

## 💻 Programs Practiced

### 📦 Tuple Programs

1. Retrieved elements using tuple slicing.
2. Counted how many times a value appears using `count()`.
3. Checked whether an element exists using the `in` operator.

### 🔢 Set Programs

4. Added a new element to a set using `add()`.
5. Removed an element using `remove()`.
6. Found the total number of unique elements using `len()`.

### 📖 Dictionary Programs

7. Created a student dictionary and accessed a value using its key.
8. Displayed all dictionary keys using `keys()`.
9. Retrieved a student's marks from a dictionary.
10. Updated a dictionary value using `update()`.

---

## 🎯 Learning Outcomes

By completing these programs, I learned how to:

- Work with immutable tuples.
- Use tuple slicing and counting methods.
- Create and manipulate sets.
- Understand that sets automatically remove duplicate values.
- Create dictionaries using key-value pairs.
- Access, retrieve, and update dictionary values.
- Display dictionary keys.
