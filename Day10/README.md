# 📘 Day 10 - Python For Loops & Loop Control

Welcome to **Day 10** of my Python learning journey! 🐍🚀

Today I continued practicing **`for` loops** and worked with lists, the `range()` function, conditions, counters, running totals, and the `break` statement.

## 📚 Topics Covered

* `for` loops
* Iterating through lists
* `range()` function
* Conditional statements inside loops
* Counter variables
* Running totals
* `break` statement
* Forward and reverse iteration

## 💻 Programs Practiced

### 🥕 Task 1 - Iterate Through a List

Created a list of vegetables and used a `for` loop to print each vegetable.

### 💰 Task 2 - Count Prices Above 100

Looped through a list of prices and counted how many values were greater than `100`.

### 🔢 Task 3 - Print Even Numbers

Used:

```python
range(2, 21, 2)
```

to print even numbers from `2` to `20`.

### 🔽 Task 4 - Countdown

Used:

```python
range(5, 0, -1)
```

to print numbers from `5` down to `1`, followed by `"done"`.

### 🛒 Task 5 - Calculate Total with Break

Calculated a running total of items and used the `break` statement to stop the loop once the total reached or exceeded `500`.

## 🎯 Learning Outcomes

By completing these programs, I learned how to:

* Iterate through list elements using `for`.
* Use `range()` with start, stop, and step values.
* Count elements that satisfy a condition.
* Create and update counter variables.
* Calculate a running total.
* Use reverse ranges for countdowns.
* Stop a loop early using `break`.
