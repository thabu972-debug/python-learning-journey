# 📘 Day 9 - Python Functions

Welcome to **Day 9** of my Python learning journey! 🐍🚀

Today I practiced **Python functions** and learned how to create reusable blocks of code using `def`, parameters, arguments, conditions, and `return`.

## 📚 Topics Covered

* Creating functions using `def`
* Calling functions
* Function parameters
* Passing arguments
* Multiple parameters
* Conditional statements inside functions
* Returning values using `return`
* Reusing functions with different arguments

## 💻 Programs Practiced

### 1️⃣ Simple Function

Created a `show_banner()` function to display multiple messages.

### 2️⃣ Function with Parameters

Created a function that accepts shop name, location, and delivery information.

### 3️⃣ Multiple Function Calls

Created a customer greeting function and called it with different names and cities.

### 4️⃣ Function with Condition

Created a delivery charge function that provides free delivery for orders of ₹300 or more.

### 5️⃣ Function with Return Value

Created a bill calculation function that multiplies price by quantity and returns the total bill.

## 🎯 Learning Outcomes

By completing these programs, I learned how to:

* Define and call Python functions.
* Pass values through parameters.
* Use functions multiple times with different arguments.
* Add conditions inside functions.
* Return calculated values from functions.
* Reduce repeated code using reusable functions.
